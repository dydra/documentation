SPARQL Symbolic Expression

A SPARQL symbolic expression is requested by specifying some variation if the media type vnd.dydra.sparql-query-algebry as the Accept header value.

Accept

application/VND.DYDRA.SPARQL-QUERY-ALGEBRA : yields the symbolic algebra expression as a text document

text/vnd.dydra.sparql-query-algebra+graphviz : yields the symbolic algebra expression as a Graphviz dot document.

image/vnd.dydra.sparql-query-algebra+graphviz+svg+xml : yields the symbolic algebra expression as a Graphviz dot graph rendered as an SVG document

application/vnd.dydra.sparql-query-algebra+graphviz+pdf : yields the symbolic algebra expression as a Graphviz dot graph rendered as an PDF document
