SPARQL Execution Record

A SPARQL execution record is requested by specifying some variation if the media type vnd.dydra.sparql-results-execution as the Accept header value.

Accept

application/vnd.dydra.sparql-results-execution : yields the execution record as a json object

image/vnd.dydra.sparql-query-results-execution+graphviz+svg+xml : renders the record to a graph and returns it as an SVG document.

text/vnd.dydra.sparql-query-results-execution+graphviz : renders the record to a graph and returns it in the form of a Graphviz .dot document.
