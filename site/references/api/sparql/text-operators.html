Text Matching

In addition to the standard SPARQL sameTerm rules which govern statement pattern unification and the regular expression support which is standard in the language, Dydra provides a mechanism for multi-valued predicate patterns to provide a text matching API.

The syntax follows the precedent establish by Jena ARQ. It employs a predicate adopted from that namespace.

prefix

IRI

arq

<http://jena.hpl.hp.com/ARQ/property#>

Where the predicate arq:textMatch appears in a basic graph pattern, it permits four parameters and two result bindings.

{ (?matchedText ?score) arq:textMatch (pattern langTag offset limit) }

The result elements are positional: the matched text result is required, while the score is optional. In a similar manner, the pattern is required while the language and slice constraints are optional. Language is significant only where the index is configured for language-specific stemming. In the current implementation, that is not supported and “simple” stemming applies.

This permits SPARQL expression variants as follows:

SELECT ?matchedText WHERE {
    ( ?matchedText )
    <http://jena.hpl.hp.com/ARQ/property#textMatch>
    ('printer:*') .
}

SELECT ?matchedText WHERE {
    ( ?matchedText ?score )
    <http://jena.hpl.hp.com/ARQ/property#textMatch>
    ('printer:*' 'EN') .
}

SELECT ?matchedText WHERE {
    ( ?matchedText ?score )
    <http://jena.hpl.hp.com/ARQ/property#textMatch>
    ('printer:*' 'EN' 0 10) .
}

The pattern syntax follows the PostgreSQL pattern syntax.

Where a query applied to a repository includes the text index predicate

<http://jena.hpl.hp.com/ARQ/property#textMatch>

a simple text index is generated for the repository. This index relies on PostgreSQL free text support with simple stemming. While that is not as sophisticated as other methods, it makes pattern matches more predictable.

This index table is static once created. In order to recreate it, delete it with a request to the related repository resource

https://dydra.com/system/accounts/<account>/repositories/<repository>/text-index
