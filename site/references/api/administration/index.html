Administrative Resources

The Dydra service API makes several resources available for users with administrative privileges to remotely administer a service by monitoring and manipulating its resources. See the examples for more details:

  • account creation

  • materialized repositories

  • System Monitoring
    • GET : status
    • GET : repository status
    • GET : service_description
    • GET : service_history
    • GET : service_statistics
  • Resource Management
    • Account Management
    • Repository Management
    • View Management
    • Index Management
  • Revision Management
    • GET : revisions
    • DELETE : all revisions
    • DELETE : selected history
  • Quality of Service Provisioning
    • PUT
    • POST
    • GET
